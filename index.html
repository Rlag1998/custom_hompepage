Shortcuts & tips

Search prefixes

  • g: Google
  • d: DuckDuckGo
  • y: YouTube
  • w: Wikipedia
  • so: Stack Overflow
  • gh: GitHub
  • mdn: MDN Web Docs
  • py: Python Docs
  • npm: npm
  • hn: Hacker News

Keyboard

  • Ctrl/⌘ + K Focus search
  • Enter Run search
  • t Toggle theme
  • n Add tile
  • s Add section (new row)
  • Drag tiles within/between sections
  • Drag section header to reorder or move to a new row
